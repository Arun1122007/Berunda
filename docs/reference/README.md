## Adding New Reference Materials

1. Place the extracted or summarized content in this directory.
2. Always name the file to reflect the source (e.g., `ncrb_report_extract.md`).
3. Add an entry to the table above.
4. In the file itself, include a header block with:
   - Source URL or citation
   - Date of extraction
   - Extraction method (manual, OCR, PDF-to-text, etc.)
   - License or usage terms
5. If the source file is large (>200 MB), store only a reference pointer and keep the original in `data/external/` or an approved external store.

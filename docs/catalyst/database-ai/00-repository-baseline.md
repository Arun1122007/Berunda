# 00 Repository Baseline

## Executive Summary
This document establishes the canonical application structure for Project Berunda prior to the complete integration of Zoho Catalyst Database and AI features.

## Canonical Application Structure

- **Repository Root**: `D:\Hack2Skill\Berunda`
- **Active Frontend**: `apps/web/`
  - Technology: React + Vite + TypeScript + Tailwind CSS
  - Verified via: `catalyst.json` client source mapping (`apps/web/dist`)
- **Active Backend**: `src/`
  - Technology: FastAPI + Python 3.10
  - Entry Point: `src/main.py`
  - AppSail Build Target: `appsail/berunda_api/` (generated by `scripts/build_appsail.ps1`)
  - Verified via: `catalyst.json` AppSail source mapping (`appsail/berunda_api`) and deployment scripts.
- **Obsolete / Duplicate Applications**: 
  - `Drishti-Crime-Viz/`: This directory appears to be an older React UI or duplicate artifact from Replit. It is explicitly ignored in Catalyst configurations and will not be deployed.
  - `apps/api/`: Appears to be an unused or legacy TypeScript Node.js backend. The canonical API is explicitly defined as Python FastAPI in `src/`.

## Active Database Configuration

- **Current ORM**: SQLAlchemy (`src/database.py`)
- **Supported Engines (Legacy)**: SQLite (`sqlite+aiosqlite://`), PostgreSQL (`postgresql+asyncpg://`), MySQL (`mysql+aiomysql://`)
- **Current Target (Catalyst)**: Catalyst Data Store
- **Required Shift**: Since Catalyst Data Store requires the `zcatalyst-sdk` and does not provide an external direct connection string compatible with generic `aiomysql` or `asyncpg` within AppSail, the SQLAlchemy direct DB engine is unsupported in production. The codebase must transition to a dual Repository Pattern (using SQLite for local dev, and the Catalyst SDK for Staging/Production).

## Active Environment Configuration
- Environment variables are sourced from `.env` in the root.
- The repository contains `.env.example` and `.env.production`. These will be cleaned and isolated to support standard Catalyst environments (Development, Staging, Production).

## Active AI Modules
- **Current Location**: `src/ai/`
- **Current Providers**: OpenAI (`src/ai/providers/openai.py`), Groq (`src/ai/providers/groq.py`), and a stub Catalyst provider (`src/ai/providers/catalyst.py`).
- **Required Shift**: All AI integrations must default to Catalyst QuickML or Zia Services natively where supported. Third-party APIs (OpenAI) should be phased out entirely if QuickML can satisfy the feature requirements, or restricted behind severe feature-flags if heavily justified.
